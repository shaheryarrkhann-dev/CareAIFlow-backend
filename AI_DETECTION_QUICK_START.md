# AI Field Detection - Quick Start Guide

## 🚀 In 3 Simple Steps to  upload

### Step 1: Upload Your PDF

```bash
curl -X POST http://localhost:4000/api/embeddings/upload \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@Disclosure_of_Charges.pdf"
```

### Step 2: Check the Response

```json
{
  "success": true,
  "message": "🤖 PDF uploaded with AI-detected field positions!",
  "template": {
    "id": "abc-123",
    "displayName": "Disclosure_of_Charges",
    "fieldCount": 8,
    "aiGenerated": true
  },
  "aiDetection": {
    "enabled": true,
    "fieldsDetected": 8,
    "usedAI": true
  }
}
```

### Step 3: Submit Form (PDFs Auto-Fill!)

```bash
curl -X POST http://localhost:4000/api/forms/{formId}/submit \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "student_name": "John Doe",
    "total_charges": 1500,
    "payment_date": "2025-10-15"
  }'
```

**Done!** All your PDFs are automatically filled and stored in S3.
